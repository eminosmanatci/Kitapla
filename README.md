# Kitapla 📚  

**Kitapla** is an Android application designed for book lovers. It allows users to explore, categorize, and keep track of their favorite books. With an elegant and user-friendly interface, Kitapla provides essential features to enhance the book-reading experience.  

---

## 🚀 Features  

- 📖 **User Authentication:** Register and log in securely to access your library.  
- 📚 **Book Tracking:** Save and categorize books you are currently reading or plan to read.  
- 🌌 **Dark Mode Theme:** Enjoy a visually appealing dark interface for a comfortable reading experience.  
- 🔍 **Smooth Navigation:** Easy access to different sections with a bottom navigation bar.  

---

## 🛠 Tech Stack  

- **Language:** Java  
- **Framework:** Android SDK  
- **UI Components:** Material Design  
- **Development Tools:** Android Studio
